# Tiny Analytics Project

A small analytics project for exploring order data.

## Data

`data/orders.csv` contains 20 sample orders with the following columns:

| Column | Description |
|---|---|
| order_id | Unique order identifier |
| order_date | Date the order was placed |
| customer | Customer name |
| amount | Order total in USD |

## Quick start

Load the CSV in your tool of choice (Python, SQL, Excel) and start exploring.
